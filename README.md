# Portfólio pessoal — CP3

Evolução do CP2 com cinco páginas: index, curriculo, formulario, multimidia e graficos.

## JavaScript
O botão **Tema escuro / Tema claro** aparece nas cinco páginas. Ao clicar, a preferência é guardada em `localStorage` com a chave `tema` e recuperada ao abrir ou atualizar qualquer página. Para testar, clique no botão e pressione F5.

O formulário usa a validação nativa do HTML e mostra uma mensagem na própria página. Os dados não são enviados a nenhum servidor e não são salvos.

## Organização
- `css/estilos.css`: estilos e responsividade
- `js/scripts.js`: tema e validação do formulário

## Publicação
Publicar no GitHub Pages com a branch `main` e a pasta `/ (root)`. Conferir as cinco páginas em janela anônima.

## Entrega
Criar commits descritivos, publicar a tag `cp3-entrega` e enviar os links do repositório e do site publicado.
